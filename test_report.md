# Отчёт о проверках

## Автоматические тесты

Команда:

```bash
python -m unittest discover -s tests -v
```

Результат контрольного запуска: **29 тестов, OK**.
Тесты подменяют внешние HTTP-ответы и не требуют ключа GigaChat.

| Компонент | Проверки |
| --- | --- |
| API | Успешный ответ, обязательность и тип message, граница 1000/1001 символ, JSON, Content-Type, лимит тела |
| LLM-клиент | Таймауты, ошибки соединения, временные HTTP-ошибки, лимит попыток, задержки, fallback |
| OAuth | Basic/form-urlencoded/UUID4, Bearer, переиспользование токена, срок действия, обновление после 401, ошибки авторизации |
| Постобработка | Структура ответа, роль, пустой текст, незавершённая генерация, ограничения модели, невалидный JSON |
| Кеш | Hit/miss, TTL, размер, составляющие ключа, отсутствие кеширования ошибок |
| Логи | JSON-формат, время этапов, корреляция по request_id, отсутствие ключей и токенов |
| TLS и настройки | Проверка scope и CA-пути, обработка TLS-ошибок, сохранение корректных настроек TLS-отладки |

## HTTP-демонстрация

Команда:

```bash
python -m tools.demo
```

Результат контрольного запуска: **7 сценариев, PASS**.
Используются локальные HTTP-серверы приложения и провайдера-заглушки с OAuth.

| Сценарий | HTTP | Результат |
| --- | --- | --- |
| Корректный запрос | 200 | OAuth и генерация, cached=false |
| Точный повтор | 200 | cached=true; всего один OAuth-вызов и одна генерация |
| Отсутствующий message | 400 | Понятная ошибка |
| 1001 символ | 400 | Ошибка длины |
| Невалидный JSON провайдера | 502 | Ошибка ответа модели |
| Закрытие порта провайдера | 503 | Ограниченные попытки и fallback |
| Закешированный запрос при сбое | 200 | cached=true |

Команда сохраняет запросы и ответы в `artifacts/demo.json`,
визуальное представление — в `artifacts/demo.html`.
Эти файлы генерируются локально и исключены из Git.

## Интеграционная проверка

Контрольный запрос к реальному GigaChat с моделью `GigaChat-2` вернул
HTTP 200 и непустое резюме. Повторный запрос вернул `cached: true`.
Проверены также Swagger UI, локальные JS/CSS, OpenAPI и загрузка CA bundle.

Доступность модели и качество ответов зависят от аккаунта и сети.
Для проверки в своём окружении используйте [ручной чек-лист](checklist.md).
